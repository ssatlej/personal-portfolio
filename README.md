# Satlej's Nova Portfolio

A modern, high-performance personal portfolio for **Satlej Sunil**, built with a dark, futuristic design language inspired by Apple, Linear, and Vercel.

## 🚀 Key Features

- **Design Language:** Dark-mode architecture (`#05070A`) with Neon Blue accents (`#22D3EE`), glowing highlights, and precise typography hierarchy.
- **Animations & Interactivity:** Built using **Framer Motion** for smooth scroll reveals, active section highlighting, subtle parallax background particles, and micro-interactions.
- **Layout Structure:** Fully responsive single-page architecture featuring 6 dedicated sections:
  1. **Home:** High-impact hero section with primary call-to-actions.
  2. **About:** Career overview and technical philosophy.
  3. **Skills:** Categorized breakdown of core competencies and tools.
  4. **Experience:** Interactive career timeline and milestone history.
  5. **Projects:** Showcase of production applications and architectural designs.
  6. **Contact:** Streamlined outreach section and direct links.
- **Performance & Accessibility:** Fully responsive across Desktop, Tablet, and Mobile devices with optimal asset loading and semantic HTML structure.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) / [Vite](https://vitejs.dev/)
- **Runtime / Package Manager:** [Bun](https://bun.sh/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
